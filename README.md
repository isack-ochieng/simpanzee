# A Little Good Morning

A responsive, interactive good-morning experience built with plain HTML, CSS, and JavaScript. It combines a swipeable slide deck, ambient animations, music embeds, image cards, and a playful question flow.

## Run locally

Open `index.html` in a browser, or serve the project with any static web server.

## Files

- `index.html` — page structure and content
- `style.css` — layout, typography, animations, and responsive styling
- `script.js` — slide navigation, carousel behavior, lightbox, and interactions

## Deployment

The project is static and can be deployed to Cloudflare Pages or another static hosting provider. Set the project root to the directory containing these files.

## Customization

Update the page copy, images, and embedded music in `index.html`. Keep interaction logic in `script.js` and visual styling in `style.css`.
